Privacy Policy

Parcel Hub is an internal workflow extension for authorized shipping teams. It processes shipment data only to support ticket parsing, email parsing, carrier handoff, label tracking, and writeback workflows.

Data Processed

The extension may process shipment-related information from supported ticket pages, supported Outlook email pages, and configured carrier pages. This can include names, company names, addresses, contact details, ticket identifiers, package details, customs descriptions, carrier selections, tracking numbers, and workflow diagnostics for the active shipping workflow.

Storage

Parcel Hub may store local settings, queue state, parsed shipment state, tracking state, writeback state, diagnostics, and prior-shipment lookup data in Chrome extension storage. Storage is used to continue the shipping workflow and recover active work.

Local Prior-Shipment Database

When prior-shipment import or lookup is used, Parcel Hub creates one hidden offscreen extension document to own its packaged SQLite WebAssembly worker and browser-local OPFS connection. This document processes prior-shipment data only for local import and lookup work, displays no user interface, accesses no websites, and loads or executes no remote code.

Sharing

Parcel Hub sends shipment data only to configured systems needed for the workflow, such as authorized ERP or ticket systems, UPS CampusShip, FedEx, and World Courier. Parcel Hub does not sell data, use data for advertising, or transfer data for unrelated purposes.

The use of information received by Parcel Hub adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements.

User Control

Users can stop extension processing by disabling or removing the extension in Chrome. Local extension storage can be cleared through Chrome extension settings. Organization-specific data access, retention, and support requests should be directed to the user's Parcel Hub administrator.

Contact

For support or privacy questions, contact the Parcel Hub administrator for your organization or use the support information linked from this site.
