Support

Parcel Hub is intended for authorized internal users. Support should start with the Parcel Hub administrator or shipping operations contact for your organization.

Before Requesting Help

  • Confirm you are on a supported ticket page, Outlook email page, UPS CampusShip page, FedEx page, or configured WorldShip handoff environment.
  • Confirm the extension is enabled in Chrome and the Parcel Hub side panel opens.
  • Capture the ticket number, carrier workflow, current page URL, and any visible Parcel Hub status message.

Common Requests

  • Access to configured ERP, ticket, or carrier systems.
  • Native host installation or health checks.
  • Recovery of queued, in-progress, or writeback-pending shipments.
  • Updates to supported email parsing or return waybill templates.

Source Repository
