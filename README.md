# Parcel Hub Website And Privacy Policy

Standalone GitHub Pages site for the Parcel Hub Chrome extension.

## Published URL

Use GitHub Pages from the `main` branch root of the public `Cashew-Milk/parcel-hub-privacy` repository.

- Website: `https://cashew-milk.github.io/parcel-hub-privacy/`
- Privacy policy: `https://cashew-milk.github.io/parcel-hub-privacy/privacy/`
- Support: `https://cashew-milk.github.io/parcel-hub-privacy/support/`

## Chrome Web Store Assets

- Icon: `assets/parcel-hub-icon.png`
- Screenshots: `assets/listing-screenshot-1.png`, `assets/listing-screenshot-2.png`, `assets/listing-screenshot-3.png`
